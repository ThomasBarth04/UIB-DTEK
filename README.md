# UIB-DTEK

Coursework from the Department of Informatics (DTEK) at the University of Bergen (UiB).

Each top-level directory is a course or category:

- `INF***` / `MAT***` / `STAT***` / `MNF130` / `EXPHIL` — course code directories with assignments and notes
- `Eksamener` — past exams
- `AOC` — Advent of Code solutions
- `coverLetters`, `gruppetime`, `lab-5` — misc coursework

Primarily Java, with material spanning several semesters.
